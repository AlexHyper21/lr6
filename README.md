# ЛР 6 — пиксельмаркет на React Bootstrap

Продолжение React-приложения из ЛР 5 (вариант 3). Интерфейс переведён на библиотеку компонентов **React Bootstrap** (Bootstrap 5).

- кастомные кнопки заменены на `Button`, карточка товара — на `Card`, селектор количества — на `InputGroup` + `Form.Control`, шапка — на `Navbar`, счётчик корзины — на `Badge`;
- страница каталога свёрстана на сетке `Container` / `Row` / `Col`: 4 колонки на широком десктопе (≥1200px), 3 на десктопе (≥992px), 2 на планшете (≥576px) и 1 на мобильном;
- глобальное состояние корзины (Redux Toolkit) сохранено.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```
